# ⚽ Football Player Performance Analytics Dashboard

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io)

A portfolio-quality, fully interactive football analytics dashboard built with Python and Streamlit. It visualises player and team performance across multiple seasons using a **synthetic, computer-generated dataset** — no external APIs or real-world data are required. The entire application lives in a single `app.py` file, making it easy to understand, extend, and deploy.

---

> ⚠️ **Data Disclaimer**
>
> All data in this dashboard is **synthetic and computer-generated**. Player names, team names, and all statistics are fabricated using NumPy random number generators with a fixed seed (`np.random.seed(42)`). This data does **not** represent real-world football players, clubs, or match statistics. It is intended solely for demonstration and portfolio purposes.

---

## Features

- 📊 **Overview Page** — five KPI metric cards (Total Players, Goals, Assists, Minutes, Avg Rating) and top-10 scorer/assister bar charts
- 🔍 **Player Analysis Page** — side-by-side comparison table for up to 5 players, Goals vs Assists scatter plot, Shots vs Goals scatter with OLS trendline
- 🏟️ **Team Analysis Page** — grouped bar charts for goals/assists per team, squad-size chart, and a sortable team league table
- 📐 **Position Analysis Page** — KPI cards per position, rating box plot, average goals/tackles charts, and a radar chart comparing all four positions
- 🎛️ **Interactive Sidebar Filters** — filter by season, team, position, and individual player; all charts update reactively
- 🌑 **Dark Football Theme** — custom CSS with a dark-pitch green colour palette (`#0e1117` background, `#00ff88` accent)
- 📥 **CSV Export** — download-filtered data as CSV from every data-heavy page
- 📈 **OLS Trendlines** — powered by `statsmodels` for scatter plot regression lines
- 🛡️ **Empty-Filter Guard** — graceful warning when the active filter combination returns no players
- 🔄 **Auto-Generated Dataset** — `football_players.csv` is created automatically on first run if absent

## Installation & Running Locally

```bash
# Clone or download the project
cd football-analysis-dashboard

# Create a virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

Then open **http://localhost:8501** in your browser.

> The first run will auto-generate `football_players.csv` if it is not already present.

---

## Deploying to Streamlit Cloud

1. Push the project to a **public GitHub repository**
2. Go to **https://share.streamlit.io**
3. Click **"New app"**, select your repository and branch
4. Set **"Main file path"** to `app.py`
5. Click **"Deploy"**

Streamlit Cloud will install dependencies from `requirements.txt` automatically. The app will be live at a public URL within a few minutes.

## Dataset

**File:** `football_players.csv`  
**Rows:** 300 (100 synthetic players × 3 seasons: 2021-22, 2022-23, 2023-24)  
**Generated by:** `generate_data()` in `app.py` using `np.random.seed(42)` for full reproducibility

### Column Schema

| Column | Type | Description |
|---|---|---|
| `player_id` | int | Unique player identifier (1–100) |
| `name` | str | Generated first + last name |
| `team` | str | One of 10 fictional club names |
| `position` | str | GK / DEF / MID / FWD |
| `season` | str | 2021-22, 2022-23, or 2023-24 |
| `age` | int | 18–38 |
| `appearances` | int | 1–38 |
| `minutes_played` | int | Appearances × ~75 (with noise) |
| `goals` | int | Position-scaled (FWDs score most) |
| `assists` | int | Position-scaled |
| `shots` | int | Correlated with goals |
| `shots_on_target` | int | ≤ shots |
| `passes` | int | 200–2500 (position-scaled) |
| `pass_accuracy` | float | 60–95 % |
| `key_passes` | int | 0–120 |
| `tackles` | int | Position-scaled (DEFs tackle most) |
| `interceptions` | int | Position-scaled |
| `clean_sheets` | int | GK/DEF only; 0 for outfield players |
| `yellow_cards` | int | 0–10 |
| `red_cards` | int | 0–3 |
| `rating` | float | 5.0–9.5 (weighted composite KPI) |

Stats are position-realistic: goalkeepers have 0 goals, defenders have high tackle counts, forwards have high shot counts, and so on.
